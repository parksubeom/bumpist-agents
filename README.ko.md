# bumpist-agents

Bumpist 파이프라인이 들어 있는 Claude Code 플러그인 마켓플레이스입니다. 아이디어 한 줄에서 Vercel 미리보기 PR까지 단계별로 진행하고, 각 단계는 따로도 쓸 수 있습니다.

> **상태: v0 (0단계).** 1단계 `/bumpist:brief`와 계약 C4(작업 공간)·C6(데이터·권한) 스키마가 있습니다. 2~4단계는 1단계, 5~9단계는 2단계 로드맵에서 추가됩니다.

설치 명령은 [영문 README](./README.md)를 보세요. 플러그인 이름이 `bumpist`라서 명령은 `/bumpist:brief`처럼 실행됩니다.
